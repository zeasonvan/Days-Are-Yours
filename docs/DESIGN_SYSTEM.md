# Design system

## 原则

温暖、克制、可读。LifeOS 是宿主的一部分，因此**表面与文字跟随 Harness 主题**，品牌色只出现在小面积装饰上；不引入自定义字体，不改变宿主布局。

## 颜色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 表面 | `--dsw-alias-bg-base` | 页面、卡片、输入框背景 |
| 次级表面 | `--dsw-alias-bg-layer-2` | hover、选中日期、胶囊正文 |
| 边框 | `--dsw-alias-border-l1` / `l2` | 卡片、分隔线、今天描边 |
| 主文字 | `--dsw-alias-label-primary` | 标题、数字、正文 |
| 次文字 | `--dsw-alias-label-secondary` | 标签、日期、提示 |
| 强调 | `--dsw-alias-brand-primary` | 主按钮、进度条、请假标记 |
| 品牌装饰 | `#354B43` 森林绿、`#E8B88F` 暖橙、`#DDE8D8` 鼠尾草、`#F5F0E6` 奶油、`#E9D9CE` 雾粉 | 团子、成就点、计划徽章（深色主题下仍保持小面积） |

对比度：正文使用 label-primary，保证 ≥4.5:1；品牌装饰不承载正文信息。

## 字体与数字

- 系统字体栈，中文行高 1.7。
- 数字统一 `font-variant-numeric: tabular-nums`；大数字 `letter-spacing:-.05em`。

## 层级

| 层级 | 尺寸 |
| --- | --- |
| 主数字（退休） | clamp(52px, 8.5vw, 86px) / 600 |
| 次数字（假期） | clamp(40px, 6vw, 58px) / 600 |
| 页面标题 | 17px / 600 |
| 卡片标题 | 13px / 600 |
| 正文 | 13–14px |
| 标签 | 11–12px |

## 组件

- **Card**：白底 + 1px 边框 + 极轻阴影（浅色 3%–13%，深色用 token 混色），圆角 18。
- **Hero**：圆角 22，主数字 + 说明 + 进度条，团子插图。
- **DateField**：本地化显示（`2026年11月9日`），聚焦切 ISO 并全选，失焦回格式；非法输入红框且不提交。
- **Nav**：四项底部导航，线性 SVG 图标，选中项用次级背景。
- **Month grid**：周一起始，单元格 46px 高，今天描边、选中填充、假期橙点、请假品牌点、补班灰点。

## 动效

只保留状态变化的即时反馈（hover 背景、选中描边），不做入场动画与循环动画。

## 空状态

每个模块都有纯文字空状态，不使用插画占位；无数据时不显示假数据。
