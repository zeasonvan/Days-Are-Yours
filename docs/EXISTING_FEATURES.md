# Existing features (countdown v0.5 → DAYS v1.1)


| 旧功能 | 旧实现 | DAYS 迁移 |
| --- | --- | --- |
| 退休倒计时 | 出生日期+性别+弹性 → 政策推算 | 保留并移入「我的」+ 首页 hero |
| 手动退休日期 | `profile.retireMode='manual'` | 保留，模式切换 |
| 出生日期/性别/入职日期 | 设置面板 | 保留，字段不变 |
| 法定假期（区间+补班） | `HOLIDAY_DATA` 2025–2027 | 原样迁移，新增全年列表与月历 |
| 下一个假期 | 右侧卡片 | 保留为首页右卡 |
| 自定义放假 | `customs[]` | 迁移为请假记录（`leaves`），并新增年假口径 |
| 语言开关 | 设置面板 | 迁入「我的」 |
| 数据 | `countdown/store/v1` | 一次性迁移到 `lifeos/store`，旧 key 只读保留 |
| 侧边栏入口 | 日历图标 | DAYS 团子图标 |
| 节日当天回退 | 农历/清明推算 | 保留作为 2027 之后的回退 |

## 未迁移

- 旧面板的「法定假期/自定义放假」双栏布局：被首页 + 日历 + 我的重新组织。
- 旧 `settings.section`（该 Harness 不呈现）。

## 新增

- 月历、年假余额、请假记录、拼假计算器、下班/发薪倒计时、每日语录与指数、时光团子、成就、愿望清单、时间胶囊、JSON 导入导出、数据重置、纯娱乐标记。
