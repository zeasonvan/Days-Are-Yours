# Product overview

**DAYS · Make Every Day Count.**
中文：让每一天都有值得期待的事情。

## 用户

中国大陆简体中文用户；关心退休、长假、年假、下班、发薪与生活小确幸的人。

## 四个问题

1. 还有多久？——退休、生日、纪念日、自定义倒计时。
2. 什么时候休息？——法定假期、请假、拼假、年假余额。
3. 今天有什么意思？——每日语录、趣味指数、团子、成就。
4. 未来想做什么？——愿望清单、时间胶囊。

## 设计取舍

- **不做传统日历系统**：日历是入口之一，不替代手机日历；DAYS 关注「距离」与「期待」。
- **不做企业仪表盘**：单一温暖的视觉语言，信息密度适中。
- **AI 不是计算器**：所有日期、假期、余额由确定性代码计算；AI 只在未来负责理解与表达。
- **不制造焦虑**：没有连续签到、没有断签惩罚、没有强制通知；团子只是陪伴。

## 四大页面

- 首页：退休 hero、下一个假期、下班/发薪/年假速览、今日语录、我的倒计时、愿望预览。
- 日历：月视图、假期与补班、请假记录、年假余额、拼假计算器。
- 趣味：下班与发薪倒计时、趣味指数、时光团子、成就。
- 我的：资料与退休设置、工作制度、愿望清单、时间胶囊、数据管理。
