# Support

- **Bug / feature request** — open an issue using the templates.
- **Data safety** — export a JSON backup from DAYS → 我的 → 数据 before experimenting.
- **Uninstall** — disable the `@local/days` bundle; your data stays in the browser until you reset it.
- **No GitHub access** — see [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md): offline ZIP/tarball/bundle, Gitee/GitLab mirrors, or a self-hosted Gitea.
- **Rollback to the legacy plugin** — enable `@local/countdown`; its data was never modified.
