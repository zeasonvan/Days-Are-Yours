# Support

- **Bug / feature request** — open an issue using the templates.
- **Data safety** — export a JSON backup from LifeOS → 我的 → 数据 before experimenting.
- **Uninstall** — disable the `@local/lifeos` bundle; your data stays in the browser until you reset it.
- **Rollback to the legacy plugin** — enable `@local/countdown`; its data was never modified.
